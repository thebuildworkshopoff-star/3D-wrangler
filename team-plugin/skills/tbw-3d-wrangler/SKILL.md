## Standalone element fidelity

Keep its identifying parts, materials, local axes and relative placements together. A dormer, for example, includes its projecting cheeks, frame profiles, glazing, sill and guards. Use a close crop of each materially different item or variant. For repeated identical instances, check one representative in isolation and check the others for placement, handedness and visible differences.

Use an available Python file tool to produce the download in the current chat. For a web environment without Blender, author a per-job mesh recipe using ordinary Python. Give each mesh a unique name, an assembly, a material name, RGB color (three integers 0–255), a pivot in inches (three numbers), vertices in **inches relative to that pivot**, and triangles (three zero-based vertex indices per triangle). X is width, Z is up, and front faces -Y. Assemble the parts as a JSON list of objects with keys name, assembly, material, color, pivot, vertices and triangles. Use counterclockwise outward winding.
